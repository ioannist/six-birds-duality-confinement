# Burnol 2004 Section 6 Extract — Step 279

Source: J.-F. Burnol, *On Fourier and Zeta(s)*, Forum Mathematicum 16 (2004), 789-840; arXiv `math/0112254v6`.

Section title:

> Sonine spaces of de Branges, novel spaces `HP_lambda`, vectors `Z^lambda_{rho,k}`, Krein string of the zeta function

Evaluator existence:

> For each `w in C`, each `k in N`, the linear forms `f -> M(f)^(k)(w)` are continuous and correspond to (unique) vectors `Z^lambda_{w,k} in K_lambda`.

Burnol note on derivative evaluators:

> Evaluators such as `Z^lambda_{w,k}` for `k>=1`, which are associated to derivatives, do not seem to have been put to use so far.

Main theorem, `0 < lambda < 1`:

> `W_lambda subset W'_lambda subset K_lambda` ... `K_lambda = W'_lambda perp Z_lambda`.

Main theorem, `lambda >= 1`:

> Let `1 <= lambda < infinity`. One has `K_lambda = Z_lambda`.

Post-definition `HP_lambda` comment:

> We thus have `HP_lambda superset Z_lambda` and the question whether this may be strict is interesting.

Theorem `omegaprime1`:

> The vectors `Z^lambda_{rho,k}`, `k<m_rho`, span `K_lambda` if and only if `lambda>=1`.

Proof line for `lambda < 1`:

> the vectors `Z^lambda_{rho,k}`, `k<m_rho`, do not span `K_lambda` if `lambda<1`.

Audit reading: Burnol supplies evaluator existence and a full zero-evaluator span only for `lambda >= 1`.  For `0 < lambda < 1`, the zero-evaluator subspace is explicitly not all of `K_lambda`; the additional `W'_lambda` component is structurally present.  The cascade-needed finite/countable `a<1` zero-evaluator linear-combination form is therefore not stated by Burnol.
