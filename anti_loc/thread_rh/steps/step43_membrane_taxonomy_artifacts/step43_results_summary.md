# Step 43: Membrane Taxonomy Theorem

## Result

This step classifies anti-localization membranes into four structural types:

1. **Intrinsic**: a single global native family currency budget
   \[
   \widehat K_j\preceq\Theta.
   \]

2. **Sectioned**: budgets on declared sections, accepted globally only by a stacked section block budget or by an explicit nonclaim excluding cross-section recombinations.

3. **Bundle/fiber**: fiberwise budgets plus uniformity/gluing control. Fiberwise finiteness is not a global membrane.

4. **Protocol-indexed**: route/protocol budgets accepted only through the stacked protocol block matrix, not route-local diagonals.

## Main theorem

For any declared membrane type \(\tau\), define its currency object \(K_\tau\) and budget \(\Theta_\tau\). Then

\[
\text{accepted membrane of type }\tau
\iff
K_\tau\preceq\Theta_\tau
\iff
\text{no unresolved native type-}\tau\text{ critical-pair witness.}
\]

If \(K_\tau\npreceq\Theta_\tau\), the spectral theorem gives a witness \(y\) with

\[
y^*(K_\tau-\Theta_\tau)y>0.
\]

## Nonclaims

The theorem is closure-relative. It does not say raw substrates, public shadows, undeclared probe families, non-transported fibers, or route-local diagonals contain no needles.

## Countermodels checked

- Section-local diagonals pass while global section block fails.
- Protocol-local budgets pass while stacked protocol union fails.
- Every fiber can be finite while the uniform bundle budget diverges.
- Public shadow can pass while hidden response direction violates the full membrane.

## Interpretation

The four membrane types are not interchangeable. Each has its own lawful surface. Overreading one as another recreates the old needle problem in a new place.
