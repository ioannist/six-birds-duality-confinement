# Nonclaim Boundary: Step 69

The duality-confinement membrane theorem does not claim that every involutive system confines objects to its fixed locus.

It requires:

- a formed closure / exact object ledger;
- a separating anti-invariant readout;
- a completed domination bridge from object displacement to carrier currency;
- anti-invariant budget collapse;
- fixed-ledger or exhaustive-ledger squeeze;
- vanishing defects or explicit defect budgets.

In particular, the theorem does not prove RH. RH is an instantiation requiring the zeta/xi-specific records.

A moving finite ledger with no tail bridge remains support-only.
