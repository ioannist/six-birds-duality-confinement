# Step 140: Ω-compatible Burnol/Müntz residual dictionary theorem

## Main result

Step 139 showed that a generic Burnol/Müntz seed is not automatically Heap--Soundararajan Ω-compatible. Step 140 replaces that generic hope with a lawful construction target:

\[
\boxed{\text{build a non-smuggled Ω-compatible Burnol/Müntz residual dictionary.}}
\]

The active dictionary is a declared family of Burnol/co-Poisson atoms whose regularized Müntz/Dirichlet shadows obey upstream prime-block cutoffs

\[
\Omega(n_j)\le K_j.
\]

This makes the GCD-log blind-sector residual small by construction, provided the Ω-compatible atoms remain dense enough in the actual Burnol/Sonine residual sector.

## Main definitions

Let

\[
M_{R,N}:Y_{R,N}\to H_N
\]

synthesize the finite residual Burnol/Sonine window.

Let \(\mathcal D_{\Omega,N}\) be the source-readable Ω-compatible atom span, and let \(P_{\Omega,N}\) be the projection onto that span.

The new density defect is

\[
\boxed{
\epsilon_{B\to\Omega,N}
=
\left\|(I-P_{\Omega,N})M_{R,N}G_{R,N}^{-1/2}\right\|.
}
\]

This is now the corrected \(c_N\)-side object: a spanning/adequacy residual of a constructible family, not a column-norm estimate.

The high-Ω seed-tail defect is

\[
\boxed{
\sigma_{K,N}
=
\left\|(I-P_{\Omega\le K})B_NG_{B,N}^{-1/2}\right\|.
}
\]

The GCD-log blind-sector estimate from Step 138 is

\[
\boxed{
\Xi_{\rm GCD,N}
\preceq
\left(L_{R,K}+T_{R,K}\sigma_{K,N}\right)^2G_{B,N}.
}
\]

## Main theorem

Assume:

\[
\epsilon_{B\to\Omega,N}\le \epsilon_N,
\]

\[
\delta_{R,K,N}=L_{R,K}+T_{R,K}\sigma_{K,N}<1,
\]

and the restricted BPRZ source theorem gives a nonblind lower frame

\[
K_q\succeq \gamma_q I,
\qquad \gamma_q\asymp \log q.
\]

Then the Ω-compatible residual source frame has positive finite strength, schematically

\[
\boxed{
\Lambda_N^{\Omega}
\gtrsim
\gamma_q(1-\epsilon_N^2)(1-\delta_{R,K,N}^2).
}
\]

If this quantity diverges and the finite windows promote through a fixed/exhaustive ledger, the GCD-log residual is source-absorbed.

## What remains open

The new load-bearing theorem is:

\[
\boxed{
\epsilon_{B\to\Omega,N}\to0
\quad\text{or at least}\quad
\epsilon_{B\to\Omega,N}\le \epsilon<1.
}
\]

This is a Burnol/Sonine density theorem under Ω-block restrictions.

## Strategic consequence

The source route now has a precise constructive fork:

\[
\boxed{\text{Ω-compatible dictionary dense enough} \Rightarrow \text{restricted BPRZ route viable}.}
\]

If not, then the missed sector is a genuine new adequacy residual:

\[
\boxed{
\Xi_{B\to\Omega,N}
=
M_{R,N}^*(I-P_{\Omega,N})M_{R,N}.
}
\]

That residual must be separately source-absorbed, tail-paid, or declared outside scope.
