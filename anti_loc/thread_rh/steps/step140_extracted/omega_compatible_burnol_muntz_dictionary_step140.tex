\section{Purpose}

Steps 130--138 identified an obstruction to importing the Bui--Pratt--Robles--Zaharescu shifted second-moment main term as an unrestricted lower frame.  The obstruction is a squarefree Boolean near-null sector of the GCD--log kernel.  Steps 131--137 then showed that the actual residual coefficient class may avoid this sector because the Burnol/M\"untz shadow passes through a zeta incidence convolution, but that the correct tail is metric-conditioned and blind-projected.

Step 139 showed that a generic Burnol/M\"untz seed is not automatically $\Omega$-compatible.  The lawful route is therefore constructive rather than generic:
\[
\boxed{\text{construct an upstream-declared $\Omega$-compatible Burnol/M\"untz residual dictionary.}}
\]

\section{Objects}

Let $Y_{R,N}$ be a finite residual Burnol/Sonine window and let
\[
M_{R,N}:Y_{R,N}\to H_N
\]
be its response synthesis map, with Gram form
\[
G_{R,N}=M_{R,N}^*M_{R,N}.
\]

Let $\mathcal P_j$ be upstream-declared prime blocks and $K_j$ upstream-declared block thresholds.  Let
\[
P_{\Omega\le K}
\]
be the projection onto coefficients satisfying
\[
\Omega(n_j)\le K_j\qquad \text{for every block }j.
\]

\begin{definition}[$\Omega$-compatible shadow]
A regularized Burnol/M\"untz shadow coefficient vector $b$ is exactly $\Omega$-compatible if
\[
P_{\Omega\le K}b=b.
\]
It is $\sigma$-compatible if
\[
\|(I-P_{\Omega\le K})b\|\le \sigma\|b\|.
\]
For a finite window $B_N$, define the uniform seed-tail defect
\[
\sigma_{K,N}=\left\|(I-P_{\Omega\le K})B_NG_{B,N}^{-1/2}\right\|.
\]
\end{definition}

\begin{definition}[$\Omega$-compatible residual dictionary]
Let $\mathcal D_{\Omega,N}\subset H_N$ be a declared atom span generated by Burnol/co-Poisson atoms whose regularized Dirichlet shadows are exactly or approximately $\Omega$-compatible.  Let $P_{\Omega,N}$ project onto $\mathcal D_{\Omega,N}$.  Define the density residual
\[
\epsilon_{B\to\Omega,N}
=
\left\|(I-P_{\Omega,N})M_{R,N}G_{R,N}^{-1/2}\right\|.
\]
\end{definition}

This is a finite Schur/adequacy residual: it measures the worst normalized residual direction not spanned by the declared $\Omega$-compatible family.

\section{GCD--log blind-sector control}

Let $\Pi_{\mathcal B_R}$ project onto a declared GCD--log blind Walsh family.  Define
\[
L_{R,K}(y)=\left\|\Pi_{\mathcal B_R}Z_yP_{\Omega\le K}\right\|,
\]
\[
T_{R,K}(y)=\left\|\Pi_{\mathcal B_R}Z_y(I-P_{\Omega\le K})\right\|.
\]
Then, for the actual seed window,
\[
\left\|\Pi_{\mathcal B_R}Z_yB_NG_{B,N}^{-1/2}\right\|
\le
L_{R,K}(y)+T_{R,K}(y)\sigma_{K,N}.
\]
Set
\[
\delta_{R,K,N}=L_{R,K}+T_{R,K}\sigma_{K,N}.
\]
Thus
\[
\Xi_{\rm GCD,N}\preceq \delta_{R,K,N}^2G_{B,N}.
\]

\section{Main theorem}

\begin{theorem}[$\Omega$-compatible residual source absorption]
Assume the following records hold on a finite residual window.
\begin{enumerate}
\item The $\Omega$-compatible residual dictionary has density defect
\[
\epsilon_{B\to\Omega,N}\le \epsilon_N.
\]
\item The blind-projected incidence gate satisfies
\[
\delta_{R,K,N}=L_{R,K}+T_{R,K}\sigma_{K,N}<1.
\]
\item The restricted BPRZ source platform gives a lower frame on the nonblind class
\[
K_q\succeq \gamma_q I,
\qquad \gamma_q\asymp \log q.
\]
\end{enumerate}
Then the source frame induced on the declared $\Omega$-compatible residual dictionary has positive finite strength, with the schematic lower bound
\[
\Lambda_N^\Omega
\gtrsim
\gamma_q(1-\epsilon_N^2)(1-
\delta_{R,K,N}^2).
\]
If this quantity diverges and the finite windows promote through a fixed/exhaustive residual ledger, the GCD--log residual is source-absorbed.
\end{theorem}

\begin{proof}[Proof sketch]
The density estimate implies that the declared $\Omega$-compatible atom span covers the finite residual window up to the defect $\epsilon_N$.  The blind-projected incidence estimate implies that the covered coefficient image has at most $\delta_{R,K,N}$ relative mass in the GCD--log blind sector.  The restricted BPRZ lower frame applies on the nonblind component with strength $\gamma_q$.  Combining the projection loss and blind-sector loss gives the displayed finite strength.  The passage from finite windows to a completed statement is not part of this finite theorem; it is exactly the fixed/exhaustive ledger gate.
\end{proof}

\section{No-smuggling conditions}

The prime blocks $\mathcal P_j$, cutoffs $K_j$, M\"untz length $X_N$, coefficient length $R_N$, conductor scale $q_N$, and atom family must be declared by the refinement/source scheme before observing which residual directions are hard.  If $K_j$ or the atom family is chosen to make $\Xi_{\rm GCD,N}$ small after seeing the target residual, the construction is smuggled.

\section{Open theorem}

The load-bearing new record is
\[
\boxed{
\epsilon_{B\to\Omega,N}\to0
\quad\text{or at least}\quad
\epsilon_{B\to\Omega,N}\le\epsilon<1.
}
\]
This is a Burnol/Sonine density theorem under $\Omega$-block constraints.  It is not supplied by generic Burnol co-Poisson density and is not supplied by scalar Heap--Soundararajan lower moments.

\section{Nonclaim boundary}

This note does not prove RH.  It does not prove that generic Burnol/M\"untz seeds have small $\Omega$-tails.  It does not import BPRZ as an unrestricted lower frame.  It only defines the lawful construction target required after the GCD--log obstruction.  The active summarized gate is\[\boxed{\epsilon_{B\to\Omega,N}<1,\quad \delta_{R,K,N}<1,\quad \gamma_q\to\infty.}\]
