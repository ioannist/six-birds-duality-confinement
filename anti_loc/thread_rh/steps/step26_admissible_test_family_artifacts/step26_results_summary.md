# Step 26: Admissible Test-Family Gate and Protocol Honesty

## Purpose

Step 26 turns the predictive probe-family matrix budget into an accepted Six-Birds-style test-family judgment.

The mathematical budget from Step 25 was

\[
\widehat K_j
=
R_jL_j\Gamma_j C_{\Gamma,j}^{\dagger}\Gamma_j^*L_j^*R_j^*
\preceq \Theta.
\]

Step 26 asks: when is this not merely a true inequality, but an admissible anti-localization test family?

## Main theorem

An anti-localization test-family record is accepted only if it passes gates for:

- formed closure/layer scope,
- exact packaged carrier,
- null-mode legality,
- declared native probe family,
- full recombination closure,
- predictive matrix budget,
- protocol honesty,
- readout agreement,
- predictive/refinement stability,
- all-six-channel status records,
- no-smuggling/no-overreading.

If the record is accepted, then for every native recombination \(y\),

\[
\sup_j
\operatorname{Cap}_{C_j}(y^*R_jL_j;\operatorname{Ran}\Gamma_j)
\le
 y^*\Theta y.
\]

So a formed closure with an accepted predictive test family has no native predictive recombination needles.

## Protocol-block theorem

If several routes or protocols are claimed, diagonal route-local budgets are not enough.

For protocol-indexed probe families \(\widetilde L^p\), stack them into

\[
\mathbb L u=(\widetilde L^p u)_{p\in\mathcal P}.
\]

The correct protocol currency matrix is

\[
\mathbb K
=
\mathbb L\Gamma C_\Gamma^\dagger\Gamma^*\mathbb L^*.
\]

A protocol-union claim requires the block budget

\[
\mathbb K\preceq\mathbb\Theta.
\]

Diagonal checks \(K^{pp}\preceq\Theta_p\) do not control mixed-protocol recombinations.

## Readout-agreement theorem

If two protocols claim the same public readout, they need a difference-capacity defect:

\[
D^{pq}
=(\widetilde L^q-\widetilde L^p)\Gamma C_\Gamma^\dagger\Gamma^*(\widetilde L^q-\widetilde L^p)^*.
\]

If

\[
K^p\preceq\Theta_p,
\qquad
D^{pq}\preceq\Delta_{pq},
\]

then for every \(t>0\),

\[
K^q
\preceq
(1+t)\Theta_p+(1+t^{-1})\Delta_{pq}.
\]

So budgets transfer across protocols only by paying an explicit readout-agreement defect.

## No-smuggling theorem

A test family selected by looking at whether anti-localization succeeds is not accepted. It is at best support-only, and if hidden, smuggled or overread.

The selected probes, carrier, response transports, and budget must be declared upstream of the anti-localization test.

## All-six-channel record

Accepted anti-localization now requires status records for:

| Role | Anti-localization reading |
|---|---|
| P1 | carrier rewrite / gauge repair |
| P2 | feasible channels / conditioning |
| P3 | route / holonomy |
| P4 | staging / sectors / refinement |
| P5 | packaging / canonicalization |
| P6 | audit / pricing |

Missing channels downgrade the claim from accepted to support-only unless explicitly outside scope with a nonclaim.

Step 26 makes family anti-localization into a real test-family judgment:

\[
\text{formed closure}
+
\text{accepted predictive family record}
\Rightarrow
\text{no native predictive recombination needles}.
\]

It also blocks the common overclaims:
