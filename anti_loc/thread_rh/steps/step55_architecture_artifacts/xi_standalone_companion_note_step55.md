# Standalone Xi companion paper note

The adequacy residual

\[
\Xi_C(D\mid L)=K_{DD}-K_{DL}K_{LL}^{\dagger}K_{LD}
\]

is strong enough to justify a standalone companion paper.

Suggested title:

**Adequacy Residuals and Blind-Spot Currency in Formed-Layer Membrane Theory**

Core results:

1. Schur-complement definition of \(\Xi\);
2. projection formula \(\Xi=T_D(I-P_L)T_D^*\);
3. optimal residual identity;
4. exact adequacy iff \(\ker L_0\subseteq\ker D_0\);
5. strict-extension monotonicity;
6. same-family saturation;
7. predictive adequacy ladders;
8. applications to NS, immune systems, cryptography, and logic.

Role in main paper:

The main manuscript should present \(\Xi\) as a central object and cite the standalone treatment if it is split out later.
