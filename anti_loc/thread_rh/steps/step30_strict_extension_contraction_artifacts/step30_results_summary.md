# Step 30 — Strict-Extension Capacity Contraction

This step proves the honest version of reflexive anti-localization contraction.

## Core conclusion

A same-package rerun cannot reduce the probe-family currency matrix. If the exact package, audit, probe family, and budget are unchanged, then

\[
\mathsf K=L_\Gamma C_\Gamma^\dagger L_\Gamma^*
\]

is unchanged up to unitary coordinate relabeling. Therefore strict capacity contraction requires a strict extension record.

## Main theorem

If a strict extension supplies

\[
\mathsf K^+\preceq \mathsf K,
\qquad
\Theta^+\succeq \Theta,
\]

then the defect

\[
\mathsf D=\mathsf K-\Theta
\]

is nonincreasing:

\[
\mathsf D^+\preceq \mathsf D.
\]

If a witness direction has strictly smaller defect, then that witness is weakened. If every unresolved step decreases a well-founded measure, completion terminates.

## Proved contraction mechanisms

1. **Audit strengthening:** if \(C^+=C+D\), \(D\succeq0\), then

\[
L(C+D)^{-1}L^*\preceq LC^{-1}L^*.
\]

2. **Feasible-subcarrier restriction:** if \(\mathcal F^+\subseteq\mathcal F\), then capacity over \(\mathcal F^+\) is no larger than capacity over \(\mathcal F\).

3. **Budget repair:** any finite state can be completed by raising \(\Theta\), but this weakens the claim rather than proving strong anti-localization.

## No-go result

Fixed-package iteration saturates. Monotone improvement also does not imply finite termination: \(K_n=1+1/n\), \(\Theta=1\), has decreasing positive defect but no finite completion.

## Interpretation

Anti-localization contraction is not generated by repeating the same closure. It is generated by strict layer growth: a new audit, carrier rewrite, package canonicalization, feasible restriction, predictive transport, or explicit claim weakening.
