# Step 37: Character-Source Frame Theorem

## Goal
Specialize strict-extension anti-invariant coercivity to the root-composite / character-source profile.

## Main theorem
Let \(L^-_\Gamma:E\to Y^-\) be the anti-invariant native probe family and let \(C_\Gamma\) be the packaged audit. For accepted source records

\[
D_s\succeq \lambda_s(Q_sL^-_\Gamma)^*\Theta_s^{-1}(Q_sL^-_\Gamma),
\]

define

\[
F_{\mathcal S}=\sum_s\lambda_sQ_s^*\Theta_s^{-1}Q_s.
\]

If

\[
F_{\mathcal S}\succeq\Lambda(\Theta^-_0)^{-1},
\]

then

\[
\mathsf K^-_+=L^-_\Gamma(C^+_\Gamma)^\dagger(L^-_\Gamma)^*
\preceq\Lambda^{-1}\Theta^-_0.
\]

Thus uniform character-source growth \(\Lambda_n\to\infty\) collapses the anti-invariant budget.

## Character specialization
For an orthogonal character decomposition

\[
Y^- = \bigoplus_{\chi\in\widehat G^-}Y_\chi,
\]

with source projections \(P_\chi\) and block budgets, the lower frame constant is

\[
\Lambda=\min_\chi \lambda_\chi.
\]

Therefore every anti-invariant character block must be covered; missing blocks leave unpriced witnesses.

## No-go results
- Trace/invariant sources do not control anti-invariant displacement.
- Missing character blocks give lower frame constant zero.
- Finite source strength gives finite budget, not exact zero-confinement.
- Target-selected character sources are not lawful unless declared upstream.

## Sanity checks
The finite checks verified:
- full character-source growth gives budget bound \(1/n\), reaching 0.01 at stage 100;
- partial growth with one bounded block stays at budget 1;
- random nonorthogonal source frames satisfied the stated lower-frame bound in all 80 trials;
- trace-only source has lower frame constant 0 on the full anti-invariant space.

## Interpretation
The root-composite profile needs a character frame. It is not enough to harden the trace, the invariant sector, or a few convenient characters. Every native anti-invariant character recombination must be priced by an upstream-visible source.
