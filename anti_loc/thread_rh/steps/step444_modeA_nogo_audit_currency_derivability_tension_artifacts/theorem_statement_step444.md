# Step 444 Theorem Statement

## Definitions

A grammar in the **constitutive-closure family** is a typed package

```text
P = (M, A, R, T)
```

where `M` is a predictive native membrane, `A` is an audit currency, `R=Xi_C(D|L)` is an adequacy residual, and `T=A_*` is the dissolving transport from the needles.tex adequacy interface.

An **audit-currency mechanism** is a typed predicate object whose accepted value is supposed to descend as the lower audit record `a^sharp` in the NDO/SAU shape

```text
[U not_down_q, C(U) down_B a^sharp].
```

An audit currency is **RH-distinguishing** on a declared finite scope if it separates the zeta/RH target from an off-critical control on that scope.

An audit currency is **derivable from non-arithmetic primitives** if its construction uses only operator-theoretic, functional-analytic, Loewner/Schur, native-probe, gamma-factor, or functional-equation primitives, and uses no zeta-values, zero tables, prime sums, modular forms, adeles, L-function special values, or RH-equivalent positivity assertions as axioms.

## Theorem-grade covered-class no-go

For the three dominant audit-currency classes tested in Steps 441-443:

1. zero-height / height-predictor audits,
2. de Branges or kernel-positivity audits,
3. Weil explicit-formula positivity audits,

no mechanism simultaneously satisfies:

```text
derivable from non-arithmetic primitives
AND

```

Each has a concrete branch that imports arithmetic content and a formal branch that is non-distinguishing.

## Diagnosis boundary

The fully universal statement over **every conceivable typed predicate** resists theorem-grade formalization because "audit-currency mechanism" is not a closed mathematical category. Thus the result is theorem-grade for the covered dominant classes and diagnosis-grade as a global universal claim.
