# Step 442 Audit Currency Redesign

## A_pos typed object

`A_pos` is a finite de Branges-style positivity-form audit currency.

### Domain

Finite test subspace generated by formal reproducing kernels

```text
span{ K_E(w_a, .) : w_a in W_scope }
```

where `W_scope` is a declared finite set of upper-half-plane test nodes in the zeta strip. No node is a zeta zero and no zero height is used.

### Predicate

The typed predicate is:

```text
Gram_A_pos = [K_E(w_a,w_b)]_{a,b} is positive semidefinite
```

plus the Hermite-Biehler inequality `|E#(z)| < |E(z)|` for `Im z > 0` on the declared finite test region.

### Candidate structure function

The intended structure function is a zeta-associated `E_xi` built from the completed xi symmetry. This is the point of the attempt: replace zero-height prediction by positivity of a canonical entire-function kernel.

## Primitive list

- Loewner cone and Schur-square accounting.
- Moore-Penrose pseudoinverse.
- Functional-equation involution `s <-> 1-s`.
- Gamma factor and conductor 1 metadata.
- Formal de Branges operations `E -> E#` and `K_E`.
- Formal `E_xi` symbol.

## Critical status

If `E_xi` is treated as a concrete analytic oracle, it imports the target zeta function into `A_pos`. If `E_xi` is treated only formally, the kernel positivity predicate cannot be derived. Thus `A_pos` avoids zero-height smuggling but fails positivity derivability.
