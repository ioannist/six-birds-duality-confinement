\[
\Xi_{\mathrm{Hall}}(\varepsilon;X)=
\#\{(x,y):0<|x^3-y^2|<|x|^{(1-\varepsilon)/2}, |x|\le X\}.
\]

\[
\Xi_{\mathrm{Pillai}}(A,B,m,n,c)=

\]
Catalan is a Type B solved special-case residual.

\]
