\section*{Step 272: Sarnak Mobius-Orthogonality Classification}

\paragraph{Carrier.}
For a zero-topological-entropy dynamical system $(X,T)$, a continuous
observable $f\in C(X)$, and a point $x\in X$, define
\[
  \Xi_{\rm MO}(N;T,f,x)=\frac{1}{N}
  \left|\sum_{n\leq N}\mu(n)f(T^n x)\right|.
\]
Sarnak's Mobius-orthogonality conjecture asserts
\[
  \Xi_{\rm MO}(N;T,f,x)\to 0
\]
for all admissible $(X,T,f,x)$.

\paragraph{Classification.}
The residual is a cross-correlation residual: one factor is arithmetic
($\mu(n)$), the other is a deterministic zero-entropy sequence
($f(T^n x)$).  It is not a Selberg-class coefficient/coefficient correlation
in the narrow sense, but it has the same typed shape as Type Ia
cross-correlation.

\paragraph{Subtype refinement.}
The Cross-Correlation Extension is refined as follows:
\[
\begin{array}{c|l}
\text{Subtype} & \text{Examples}\\\hline
\text{Ia-pure-arithmetic} & \text{SOC, full Selberg orthonormality}\\
\text{Ia-arithmetic-dynamical} & \text{Sarnak Mobius orthogonality}\\
\text{Ib} & \text{Montgomery/Hejhal zero correlations}\\
\text{II} & \text{Rudnick-Sarnak/Katz-Sarnak family zero correlations}
\end{array}
\]

\paragraph{Excluded alternatives.}
MO is not a Subconvexity residual: qualitative MO gives PNT via the trivial
system but not an RH-strength square-root bound without a quantitative rate.
It is not a Zero-Density residual, since it does not count zeros in
rectangles.

\paragraph{Verdict.}
\[
  \boxed{\texttt{V\_sarnak\_in\_cross\_correlation\_Ia}}.
\]
No proof of MO or RH is claimed.
