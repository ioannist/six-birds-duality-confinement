# Nonclaim Boundary

This step does not prove RH and does not test an actual off-critical zero.

The points `0.7+iT`, `0.3+iT`, and `0.5+14.0i` are not zeta zeros. The calculation uses only the Step 292 raw proxy

```text
delta_Dk(s) = (zeta*M(G_star))^(k)(s)
```

at arbitrary points. The full Burnol/Sonine Branch C matrix element is a zero-spectral object and is not directly defined at these hypothetical off-critical nonzeros.

The conclusion is therefore only a heuristic sensitivity check on the raw proxy.
