2. The scaling site
The scaling site [0, ∞) ⋊ N× is, as a site, given by a small category C endowed with a Grothendieck
topology J. The objects of C are the (possibly empty) bounded open intervals Ω ⊂ [0, ∞). The morphisms
between two objects are defined by HomC (Ω, Ω′ ) = {n ∈ N× ∣ nΩ ⊂ Ω′ }, if Ω ≠ ∅ and by HomC (∅, Ω′ ) ∶= {∗}
i.e. the one point set, for any object of C. Thus the empty set is the initial object of C. The category
C admits pullbacks. Indeed, let Ωj ≠ ∅ (j = 1, 2) and consider two morphisms φj ∶ Ωj → Ω given by
integers nj ∈ HomC (Ωj , Ω). Let n = lcm(nj ) be their lowest common multiple, write n = aj nj and let
Ω′ ∶= {λ ∈ [0, ∞) ∣ aj λ ∈ Ωj , j = 1, 2}. If Ω′ = ∅ the initial object is the pullback. Otherwise this gives an
object Ω′ of C and morphisms aj ∈ HomC (Ω′ , Ωj ) such that φ1 ○ a1 = φ2 ○ a2 . One sees that (Ω′ , aj ) is
the pullback of the pair φj ∶ Ωj → Ω. Since the category C has pullbacks we can describe a Grothendieck
topology J on C by providing a basis (cf. [8], Definition III.2).
Proposition 2.1 (i) For each object Ω of C, let K(C) be the collection of all ordinary covers {Ωi ⊂
Ω, i ∈ I ∣ ∪Ωi = Ω} of Ω. Then K defines a Grothendieck topology J on C.
(ii) The category Sh(C, J) of sheaves on (C, J) is canonically isomorphic to the category of N× equivariant sheaves on [0, ∞).
Definition 2.2 The scaling site [0, ∞) ⋊ N× is the small category C endowed with the Grothendieck topology J. The scaling topos is the category Sh(C, J).
