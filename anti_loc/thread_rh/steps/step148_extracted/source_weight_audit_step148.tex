\section{Main warning: cumulative source budget is incompatible with nonzero residual mass}

\begin{theorem}[Raw cumulative source-budget no-go]
Let \(G_R\succeq0\), \(K_R^\omega\succeq0\), and suppose
\[
F_N^\Omega\succeq \Lambda_N^\Omega G_R,
\qquad
\Lambda_N^\Omega\to\infty.
\]
If
\[
m_\omega:=\operatorname{tr}(G_RK_R^\omega)>0,
\]
then
\[
\operatorname{tr}(F_N^\Omega K_R^\omega)
\ge
\Lambda_N^\Omega m_\omega
\to\infty.
\]
Consequently,
\[
\boxed{
\sup_N\operatorname{tr}(F_N^\Omega K_R^\omega)<\infty
\quad\Longrightarrow\quad
\operatorname{tr}(G_RK_R^\omega)=0.
}
\]
If the weighted ledger is separating on the visible residual zero directions, this implication is already the residual-zero conclusion.
\end{theorem}

\begin{proof}
Since \(F_N^\Omega-\Lambda_N^\Omega G_R\succeq0\) and \(K_R^\omega\succeq0\) is trace-class, monotonicity of the trace pairing gives
\[
\operatorname{tr}(F_N^\Omega K_R^\omega)
\ge
\Lambda_N^\Omega\operatorname{tr}(G_RK_R^\omega).
\]
If \(m_\omega>0\) and \(\Lambda_N^\Omega\to\infty\), the right hand side diverges. The contrapositive proves the assertion.
\end{proof}

\section{Interpretation}
The bounded source-budget condition cannot be closed by merely choosing faster-decaying fixed positive weights while keeping the same cumulative source frame. If \(K_R^\omega\) has any positive residual mass in the \(G_R\)-metric, the cumulative lower frame forces
\[
\operatorname{tr}(F_N^\Omega K_R^\omega)\to\infty.
\]
Thus the condition
\[
\sup_N\operatorname{tr}(F_N^\Omega K_R^\omega)<\infty
\]
is not a harmless normalization gate. It is a contradiction/source-work record: paired with the lower-frame theorem, it already forces the completed residual ledger to vanish.

\section{Normalized audit frames are useful but do not squeeze}
Define a normalized source audit frame
\[
A_N^\Omega:=\frac{1}{1+\Lambda_N^\Omega}F_N^\Omega.
\]
Then
\[
A_N^\Omega\succeq \frac{\Lambda_N^\Omega}{1+\Lambda_N^\Omega}G_R.
\]
A bounded trace condition
\[
\sup_N\operatorname{tr}(A_N^\Omega K_R^\omega)<\infty
\]
can often be made compatible with trace-class weights, but it no longer implies residual collapse. It only supplies boundedness of the normalized audit.

So the route separates two roles:
\[
\boxed{
F_N^\Omega\text{ cumulative forcing frame: gives divergence/zero-squeeze if budget is bounded.}
}
\]
\[
\boxed{
A_N^\Omega\text{ normalized audit frame: compatible with weights but does not by itself collapse residual mass.}
}
\]

\section{A lawful shell-weight construction for bounded audit families}
Let \(\mathcal A_N\succeq0\) be a declared bounded audit family, not the cumulative forcing frame. For dyadic zero-height shells
\[
\mathcal Z_j=\{(\rho,k):2^j\le 1+|\Im\rho|<2^{j+1}\},
\]
set
\[
n_j=\#\mathcal Z_j,
\quad
E_j=\sup_{(\rho,k)\in\mathcal Z_j}\|\Pi_RY^a_{\rho,k}\|^2,
\quad
S_j=\sup_N\sup_{(\rho,k)\in\mathcal Z_j}\langle \mathcal A_N\Pi_RY^a_{\rho,k},\Pi_RY^a_{\rho,k}\rangle.
\]
If \(E_j,S_j<\infty\), define
\[
\boxed{
\omega^{\rm src}_{\rho,k}
=
\frac{2^{-j}}{(1+n_j)(1+E_j)(1+S_j)}
\qquad ((\rho,k)\in\mathcal Z_j).
}
\]
Then the weighted ledger is trace-class and source-audit compatible:
\[
\operatorname{tr}K_R^{\omega^{\rm src}}<\infty,
\qquad
\sup_N\operatorname{tr}(\mathcal A_NK_R^{\omega^{\rm src}})<\infty.
\]
This theorem is valid for normalized or auxiliary audit families. It does not repair the raw cumulative source-budget no-go, because for \(\mathcal A_N=F_N^\Omega\) the shell envelope \(S_j\) is infinite whenever the residual evaluator is nonzero and \(\Lambda_N^\Omega\to\infty\).
