# Nonclaim Boundary for RH Membrane Target

This setup does not claim RH.

It assumes zeta/primes is a formed closure and native membrane. It does not assume that the native membrane covers off-critical-zero dissolving probes.

It does not claim Weil positivity already yields a Douglas contractive factorization.

It does not claim finite zero windows prove exact confinement without a tail/exhaustivity bridge.

It does not claim any particular Hilbert-space carrier is correct.

It does not allow post-hoc source selection: source ladders must be upstream-visible and declared before the confinement budget is tested.

It does not treat trace equality, scalar positivity, or invariant-sector control as anti-invariant Loewner domination.
