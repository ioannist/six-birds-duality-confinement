# Step 130 — GCD-log kernel lower-frame audit

## Main result

The unrestricted lower-frame import from the Bui–Pratt–Robles–Zaharescu shifted second-moment main term fails.

The normalized Step 129 main kernel is

\[
\widetilde K_q(m,n)=\frac{(m,n)}{\sqrt{mn}}\left(C_q-\log\frac{mn}{(m,n)^2}\right),
\qquad C_q=\log q+O(1).
\]

The desired full matrix source certificate would be

\[
\widetilde K_q\succeq c_0\log q\,I.
\]

Step 130 shows that this cannot hold on the full coefficient space.

## Squarefree Boolean-cube obstruction

For squarefree integers generated by primes \(p\le y\), the GCD kernel diagonalizes exactly.  With

\[
A_s(m,n)=\frac{(m,n)^{2s}}{(mn)^s},
\]

we have

\[
\widetilde K_q=C_qA_{1/2}+\partial_s A_s|_{s=1/2}.
\]

On the squarefree Boolean cube, the all-minus vector has eigenvalue

\[
\lambda_-(q,y)=
\prod_{p\le y}(1-p^{-1/2})
\left(C_q+
\sum_{p\le y}\frac{p^{-1/2}\log p}{1-p^{-1/2}}
\right).
\]

Taking \(y\asymp \kappa\log q\), so that the whole cube lies inside \(n\le q^\kappa\), gives

\[
\lambda_-(q,y)
\le
(\log q+O(\sqrt{\log q}))
\exp\left(-(2+o(1))\frac{\sqrt{\kappa\log q}}{\log\log q}\right)
\to0.
\]

So no \(\gg\log q\) lower frame, and not even a uniform positive lower frame, is available on the unrestricted coefficient space.

## Interpretation

This does not contradict the BPRZ theorem.  The weighted character sum is positive as a Gram form.  The point is that the shifted-limit main kernel has near-null directions on the full coefficient space.

Therefore BPRZ cannot be imported wholesale as

\[
G_{q,w}\succeq \gamma_qH_q,
\qquad \gamma_q\asymp\log q,
\]

unless we restrict to a residual coefficient class that avoids the squarefree blind sector, or add another source component that charges it.

## New residual

Define the GCD-log blind-sector residual

\[
\Xi_{\rm GCD,N}=R_N^*\Pi_{\rm sf}R_N.
\]

This measures the part of the residual coefficient image that falls into the squarefree Boolean near-null sector.

## Bottom line

The BPRZ platform remains useful, but only as a restricted-class or complemented-source theorem.
