# U^flat_R: Rewrite-System-Only Mode B Design

Carrier: a finite term-rewriting system.  There is no explicit state set and no graph.

## Term Signature

Terms are generated by:

- H(chi,k): Hecke evaluator atom.
- Z(rho,k): zeta evaluator atom.
- M[H,Z]: magnitude residual term.
- P[H,Z]: phase residual term.
- O[H,Z]: operator residual term.
- Bottom: defect term.
- Tau_R[H]: attempted transfer term produced by rewrite normalization.

## Rewrite Rules

- H(chi,k) -> pair(log|H_chi,k|, arg H_chi,k).
- Z(rho,k) -> pair(log|Z_rho,k|, arg Z_rho,k).
- M[H,Z] -> |log|H| - log|Z||.
- P[H,Z] -> |arg H - arg Z| modulo 2*pi.
- O[H,Z] -> missing_certificate unless a finite operator condition is produced.
- Bottom -> defect.
- Tau_R[H(chi,k)] is not primitive.  It is produced by the admissible normalization rewrite N_R using term features.

## Stage III Rewrite Normalization

N_R uses only term-local features:

- x = log|H(chi,k)|
- dx = x_k - x_{k-1} when available, else 0
- k, 1/k, x*dx

Magnitude rewrite:
log|Tau_R(H)| = theta dot [1, x, dx, k, 1/k, x*dx].

Phase rewrite:
arg Tau_R(H) = arg H + eta dot [1, x, dx, k, 1/k, sin(arg H), cos(arg H)].

This design is not a relabeling of state or graph carriers; rewrite rules operate directly on terms and normal forms.
