# Step 42: Layer Membrane Transfer Theorem

## Goal

Prove when an accepted anti-localization membrane on one lawful carrier transfers to another carrier, public shadow, protocol surface, or exactification bridge.

## Core theorem

For a source membrane with currency

\[
K=W^*W,
\qquad W=C^{\dagger/2}L^*,
\]

and a target membrane

\[
K'=W'^*W',
\qquad W'=C'^{\dagger/2}L'^*,
\]

a lawful witness-transfer record is

\[
W'=UWR+D,
\qquad U^*U\preceq \alpha I,
\qquad D^*D\preceq E_{\rm tr}.
\]

Then for every \(t>0\),

\[
\boxed{K'\preceq (1+t)\alpha R^*KR+(1+t^{-1})E_{\rm tr}.}
\]

Thus if \(K\preceq\Theta\), the target inherits the membrane with any budget satisfying

\[
(1+t)\alpha R^*\Theta R+(1+t^{-1})E_{\rm tr}\preceq\Theta'.
\]

## Variational transfer

A more concrete sufficient condition is:

\[
L'=R^*LT+\Delta,
\qquad T^*CT\preceq\alpha C'.
\]

If the residual has currency

\[
K_\Delta=\Delta C'^{\dagger}\Delta^*,
\]

then

\[
\boxed{K'\preceq (1+t)\alpha R^*KR+(1+t^{-1})K_\Delta.}
\]

## Compression DPI

If \(V\subset E\) is a lawful feasible subcarrier, then

\[
\boxed{K_V\preceq K.}
\]

Restricting feasible states cannot increase native response purchasable per unit audit energy. Equality requires the ambient minimum-energy representers to already live in the compressed carrier, modulo legal null directions.

## Public shadow warning

For a public readout \(P:Y\to Y_{\rm pub}\), the public shadow

\[
K_{\rm pub}=PKP^*
\]

inherits the lawful membrane. But the converse is false: a shadow can forget a hidden native direction with arbitrarily large capacity.

## Protocol transfer

Protocol transfer must use the stacked block matrix

\[
\mathbb K=\mathbb L C^\dagger\mathbb L^*.
\]

Diagonal route-local transfer does not certify mixed-protocol recombinations.

## Layman interpretation

A membrane transfers only if the new layer’s ways of being poked can be paid for by the old layer’s actual minimum-energy receipts. Matching public outputs is not enough. The proof must transport the receipts themselves, or explicitly pay for the missing part as a defect.

## Bottom line

\[
\boxed{\text{membrane transfer} = \text{contractive witness descent} + \text{explicit defect ledger}.}
\]

This blocks the overread:

\[
\text{public-shadow anti-loc}\Rightarrow\text{lawful-carrier anti-loc}.
\]

The implication is one-way unless a reconstruction bridge is earned.
