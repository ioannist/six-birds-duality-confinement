
# Positioning note

Recommended title:

**Blind-Spot Currency and Adequacy Residuals: A Standalone Xi-Theory for Formed-Layer Membranes**

The central claim:

\[
\Xi_C(D\mid L)=\text{what the layer does not know about its own possible dissolution.}
\]

The paper should be short and theorem-dense. It is not an application paper and not a Six Birds simulation. It is a reusable linear/Schur-duality theorem package with direct membrane-theoretic interpretation.

Relationship to the main paper:

- Main membrane paper: native predictive probe-family currency and no native needles.
- Xi paper: adequacy/exhaustivity of native probes against dissolving probes.
- RH root-composite route: \(D\) is off-fixed zero displacement; \(L\) is the completed native carrier response.
- NS route: \(D\) is pointwise blow-up/gradient/vorticity concentration; \(L\) is energy/enstrophy/shell/audit-feature response.
