# Step 39: Obstruction Ledger for the Root-Composite RH Route

## Purpose

Steps 32--38 gave a forward implication:

\[
\text{anti-linear duality}
+
\text{explicit-formula domination}
+
\text{character-source coercivity}
\Rightarrow
\text{zero/root confinement}.
\]

Step 39 records the contrapositive: if confinement is not obtained, the failure must be assigned to a named obstruction slot.

## Main theorem

Let \(\mathsf A_Z\) be the zero-side anti-invariant displacement matrix and \(\mathsf K^-\) the completed carrier-side anti-invariant currency matrix. Suppose

\[
\mathsf A_Z\preceq (1+t)\mathsf K^-+(1+t^{-1})E_{\rm EF},
\]

and

\[
\mathsf K^-\preceq \Lambda^{-1}\Theta^-_0+E_{\rm src}.
\]

Then

\[
\mathsf A_Z
\preceq
(1+t)(\Lambda^{-1}\Theta^-_0+E_{\rm src})
+
(1+t^{-1})E_{\rm EF}.
\]

For visible displacement threshold \(\varepsilon>0\), this gives

\[
\sum_{z:\|P_-\psi(z)\|\ge\varepsilon}w_z
\le
\varepsilon^{-2}
\operatorname{tr}
\left[(1+t)(\Lambda^{-1}\Theta^-_0+E_{\rm src})+(1+t^{-1})E_{\rm EF}\right].
\]

If \(\Lambda\to\infty\), \(E_{\rm src}\to0\), and \(E_{\rm EF}\to0\), then visible off-fixed root mass vanishes.

## Obstruction alternative

If off-fixed mass persists, then at least one of these must fail:

1. explicit-formula domination;
2. full anti-invariant character/source frame;
3. coercivity growth;
4. null-mode legality;
5. zero visibility/exhaustivity;
6. closure/promotion/finite-to-continuum control;
7. scope/nonclaim honesty.

## RH interpretation

For RH, \(J(s)=1-\overline{s}\), so \(\operatorname{Fix}(J)=\{\Re(s)=1/2\}\). Off-critical zeros produce anti-invariant displacement. The root-composite route can prove confinement only if that displacement is contractively paid by the completed carrier and the anti-invariant currency budget collapses.

If confinement is not obtained, Step 39 says where the obstruction must be recorded.

## Nonclaim

This does not prove RH. It states a precise obstruction ledger for the RH-facing root-composite anti-localization route.
