# Nonclaim Boundary

This step does not prove RH, GRH, or a theorem about all Dirichlet L-functions.

The calculation tests a finite set of 50 zeros for the primitive character `chi_3`. It uses the close-pair-only Hadamard contribution and does not include the full regular Hadamard remainder. The result is therefore an analytical diagnostic for the observed exceptions, not a complete sign theorem.
