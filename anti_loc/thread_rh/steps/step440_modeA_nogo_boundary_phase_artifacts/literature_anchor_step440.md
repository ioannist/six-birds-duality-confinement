# Step 440 Literature Anchor

## Berry-Keating 1999

Berry and Keating proposed the classical Hamiltonian `H_cl=xp` as a Hilbert-Polya direction and studied the quantum symmetrized dilation operator `(xp+px)/2`. The central obstruction is domain/self-adjointness plus the absence of a natural mechanism producing exact zeta-zero ordinates.

## Sierra-Rodriguez-Laguna 2011

Sierra and Rodriguez-Laguna, PRL 106, 200201, modified the Hamiltonian to

```text
H = x(p + l_p^2/p)
```

to close classical orbits and recover the average Riemann counting law via Bohr-Sommerfeld quantization. The framework uses self-adjoint extension/boundary phase data, and different choices correspond to zeta versus Dirichlet L-function variants.

## Bender-Brody-Müller 2017

Bender, Brody, and Müller, PRL 118, 130201, proposed a Hamiltonian for the zeros of the Riemann zeta function using non-Hermitian/PT-symmetric ideas. The boundary/phase information tied to the zeta phase is the arithmetic input in the construction.

## Bellissard 2017

Bellissard's 2017 comment, arXiv:1704.02644, criticizes the Bender-Brody-Müller proposal and identifies the self-adjoint/spectral compatibility step as load-bearing and not established. This independently supports treating boundary-phase target selection as structural, not cosmetic.

## von Neumann extension theory

Von Neumann self-adjoint extension theory states that a densely defined symmetric operator with deficiency indices `(n_+, n_-)` has self-adjoint extensions iff `n_+=n_-`; if both equal `n`, the extensions are parameterized by `U(n)`. Thus a boundary phase in the `(1,1)` case is part of the operator data, not an optional afterthought.
