\section{Why this avoids the Conrey--Li trap}
The hybrid route is not a de Branges/RKHS shift-positivity ansatz. Instead, it uses a semilocal Weil/Sonin carrier with explicit support, vanishing, quotient, source, tail, and adequacy records.  Any proposed finite or infinite positivity condition must be tested against the Conrey--Li obstruction by verifying that it is not equivalent to the refuted RKHS positivity.
