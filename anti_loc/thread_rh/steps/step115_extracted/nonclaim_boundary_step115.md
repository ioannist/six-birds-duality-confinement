# Step 115 nonclaim boundary

This step does not claim RH.

It does not claim that every shifted Sonin/prolate boundary packet is a Burnol co-Poisson atom.

It does not claim

\[
\mathcal B\subseteq P_a.
\]

It does not claim a zeta-factorization for

\[
\mathfrak B_{\ell,a}=J_aP_\infty\tau_\ell(I-P_\infty).
\]

It proves only the gate:

\[
M(\mathfrak B_{\ell,a}u)=\zeta\alpha_{\ell,u}
\Rightarrow
\operatorname{Ran}\mathfrak B_{\ell,a}\subseteq P_a.
\]

It also defines the residual if that gate is not earned:

\[
\Xi^{\rm BC}_{\ell,a}=\mathfrak B_{\ell,a}^*\Pi_{Y_a}\mathfrak B_{\ell,a}.
\]

The residual must be made zero by theorem, paid by vanishing defect, or absorbed by source coercivity.
