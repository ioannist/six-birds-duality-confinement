# Step 115: Zeta-factorization attempt for the boundary block

## Result

The clean route would be a lawful factorization

\[
M(\mathfrak B_{\ell,a}u)(s)=\zeta(s)\alpha_{\ell,u}(s),
\]

because Burnol's co-Poisson subspace is the perpendicular complement of the zero-evaluator span. Such a factorization would force every zero-evaluator to annihilate the shifted boundary packet, hence

\[
\operatorname{Ran}\mathfrak B_{\ell,a}\subseteq P_a.
\]

## Main finding

The raw log-shift does not create a zeta factor. In Mellin variables it supplies a nonzero exponential multiplier. Therefore the zeta divisor, if it exists, must come from a genuine Sonin/co-Poisson theorem, projection cancellation, or an additional declared source/quotient record.

So the zeta-factorization route remains unearned.

\[
\Xi^{\rm BC}_{\ell,a}
=\mathfrak B_{\ell,a}^*\Pi_{Y_a}\mathfrak B_{\ell,a}\succeq0.
