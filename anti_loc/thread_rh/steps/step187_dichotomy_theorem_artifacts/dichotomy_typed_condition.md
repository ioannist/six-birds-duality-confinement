# Framework RH-Carrier Dichotomy Theorem

## Statement

Let `C` be a typed primary carrier supporting a residual `Xi_C` aimed at an
RH-analogous statement about an L-function or zeta function `L_C`.

The framework dichotomy has two branches.

### CRE Branch

If `C` is classically-RH-equivalent (CRE), meaning either `C` is a named
classical Riemann-RH approach or closure of `Xi_C` is logically equivalent to
Riemann RH, then `C` exhibits CRCFT in at least one mode:

- `CRCFT-CTMT`: post-reduction matrix-element terminus;
- `CRCFT-TE`: pre-reduction target-equivalence;
- `CRCFT-BF`: carrier-comparison or spectral-type failure.

The framework output is the typed external-content interface naming the
precise obstruction.

### Non-CRE Branch

If `C` is non-CRE and the RH analog for `L_C` has been proved with a complete
native spectral, cohomological, or algebraic ledger, then the framework yields
native closure:

```tex
Xi_C = 0.
```

## Consequence

Applied to RH-analogous carriers, the framework produces:

- typed obstruction interfaces for CRE carriers;
- native closure certificates for non-CRE carriers with proved native ledgers.

A live Riemann RH route therefore needs either an external theorem resolving a
CRCFT obstruction or a non-CRE carrier with a bridge that transports native
closure to Riemann RH. No such bridge is inherited in the current records.

## Coverage Conjecture

Every RH-analogous typed carrier is classified by this dichotomy into exactly
one of CRCFT foreclosure or native closure. No third class exists.

Status: conjecture, supported by 7 carriers. It is refutable by exhibiting an
RH-analogous carrier outside both classes.

## Relationship to CTMT and CRCFT

CTMT is the post-reduction matrix-element terminus condition. CRCFT contains
CTMT and covers CRE foreclosure modes. The dichotomy contains CRCFT as its
CRE branch and adds the non-CRE native-closure branch.
