## 8. Manifest update protocol

For every new declaration you produce, append an entry to the relevant
per-axis manifest (`lean/manifests/<axis>_manifest.toml`). Schema (all
fields required, empty string acceptable for free-form text):

```toml
[[claim]]                       # use [[definition]] for definition_kind entries
paper_label = "lem:duality_confinement:<short-name>"
paper_section = "<section title>"
description = "<one-line summary>"
status = "theorem"              # one of: definition, theorem, partial, unformalized
                                # axiomatic is documented but forbidden in this repo
lean_subproject = "."
lean_module = "SixBirdsDualityConfinement.DualityConfinement.<Module>"
lean_decl = "SixBirdsDualityConfinement.DualityConfinement.<Module>.<shortName>"
notes = ""
```

Use `[[definition]]` for entries whose paper kind is `definition`;
use `[[claim]]` for theorem, lemma, proposition, and corollary kinds.

The `status` field must match the paper kind: definitions → `status =
"definition"`, theorems/lemmas/propositions/corollaries → `status =
"theorem"`. Use `partial` only when you've mechanized a supporting
fragment but not the full statement. Use `unformalized` only as a
placeholder to register an item you couldn't complete this turn.

## 10. Forbidden Lean tokens

These tokens are forbidden as Lean declarations or syntax anywhere in
`lean/SixBirdsDualityConfinement/`:

- `sorry`
- `admit`
- `axiom`
- `opaque`
- `constant`

**Scope of the rule.** The validator `scripts/check_lean.py` strips
Lean comments (both `--` line comments and `/-! … -/`, `/- … -/` block
comments) before scanning, so the rule binds the **active source
content** only. Prose mentions of these words inside docstrings or
comments — for instance, "this module deliberately avoids `axiom`" —
are NOT violations. Out-of-scope obligations live in the inventory
toml, not as Lean `axiom` declarations.

If you need to record an out-of-scope claim that downstream theorems
depend on (such as a structural recognition source identified in the
RH proposal), encode it as a typed `structure` carrier with a `Prop`
field, and have downstream theorems take a value of that structure as
an explicit hypothesis parameter.
