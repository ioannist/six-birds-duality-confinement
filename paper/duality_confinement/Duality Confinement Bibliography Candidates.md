### Topic I. Operator square roots and range inclusion

No additional BibTeX entry is recommended for Topic I. The most economical and best-verified choice is to reuse `Conway1990` from Topic A for operator square roots, polar decomposition, and range-inclusion background, together with the already-shared `Douglas1966` for the range-inclusion theorem itself.

## Per-entry notes

| Topic | Key | Note |
|---|---|---|
| A | `ReedSimon1980` | Standard mathematical-physics functional-analysis reference for Hilbert spaces, bounded operators, spectral theory, unbounded-operator preliminaries, and trace-ideal background. It is the strongest single general reference for the paper's operator-theoretic vocabulary, while avoiding the already-cited `Simon2005`. |
| A | `Conway1990` | Graduate-level Hilbert-space/operator-theory text with clean treatments of bounded operators, adjoints, compact operators, Fredholm theory, and unbounded operators. It also serves Topic I for square-root and polar-decomposition background if only one textbook is desired there. |
| A | `Rudin1991` | Broad functional-analysis reference for locally convex spaces, Hilbert spaces, Banach-space tools, and operator-theoretic foundations. It is a good alternative to Reed--Simon or Conway if the paper wants a standard pure-mathematics citation. |
| A | `GohbergKrein1969` | Classical source on compact and nonselfadjoint operators, characteristic values, and operator ideals. It is useful as the historical trace-ideal/Schatten-class companion to `Simon2005`, but should be included only if an additional older specialist reference is desired. |
| B | `Bhatia1997` | Canonical matrix-analysis text for positive semidefinite order, eigenvalue inequalities, matrix means, and Loewner-order arguments. This is the best compact citation for the paper's typed positive cone and positive-matrix analogy. |
| B | `HornJohnson2013` | Comprehensive modern matrix-analysis reference, especially useful for positive semidefinite matrices, rank-one computations, Schur complements, and matrix inequalities. It is a natural alternative or complement to Bhatia. |
| B | `Loewner1934` | Primary source for operator-monotone matrix functions and the Loewner perspective. List first when discussing the historical origin of monotone matrix functions rather than general matrix-analysis background. |
| B | `Bhatia2007` | Modern focused treatment of positive definite matrices, matrix means, operator monotone functions, and order inequalities. It fits especially well if the DC discussion wants the Loewner-order side without invoking a broad matrix-analysis encyclopedia. |
| C | `HardyLittlewoodPolya1952` | Canonical classical source for AM--GM, convexity, majorization, and fundamental inequalities. This is the primary citation for the optimized scalar trace budget using AM--GM. |
| C | `Mitrinovic1970` | Standard systematic reference for analytic inequalities, suitable as a modern supplement to Hardy--Littlewood--Pólya. Use if the paper wants an additional classical-inequality handbook beyond the canonical source. |
| C | `Folland1999` | Standard graduate real-analysis text covering measure, integration, and measure-theoretic inequalities; it is adequate for Markov/Chebyshev-style estimates in the quantitative-confinement theorem. One such measure-theory reference is enough. |
| D | `ReedSimon1975` | Canonical mathematical-physics reference for Fourier analysis and self-adjointness, including symmetric/self-adjoint operators, extensions, perturbation theory, and quantum-mechanical applications. It is the strongest citation for the self-adjointness prediction. |
| D | `Hall2013` | Modern graduate text explaining quantum theory in mathematical language, with explicit chapters on bounded and unbounded self-adjoint operators and the spectral theorem. It is more accessible than Reed--Simon and fits a discussion-section citation well. |
| E | `StreaterWightman2000` | Canonical rigorous axiomatic-QFT reference for PCT/CPT, spin-statistics, and the mathematical structure behind relativistic quantum fields. Use this as the primary CPT theorem source. |
| E | `BogoliubovLogunovOksakTodorov1990` | Substantial mathematical treatment of general QFT principles, including locality, covariance, and CPT-type structural results. It is an appropriate second rigorous source if the paper wants depth beyond Streater--Wightman. |
| E | `Weinberg1995` | Standard physics reference for foundational QFT, symmetries, particles/antiparticles, charge conjugation, and the representation-theoretic structure of fields. It is useful for the broad physics-facing discussion. |
| E | `PeskinSchroeder1995` | Widely used graduate QFT textbook covering gauge theories, QED/QCD, discrete symmetries, and particle--antiparticle language. It is a pragmatic citation for charge conjugation and gauge-invariance background. |
| E | `Bleecker1981` | Mathematical gauge-theory reference emphasizing principal bundles, connections, curvature, and variational principles. Use this if the gauge-invariance prediction should be grounded in mathematical gauge theory rather than physics QFT. |
| F | `Weil1948a` | Canonical primary source for Weil's algebraic-geometric proof framework for curves over finite fields. This should be listed first for the function-field RH prediction. |
| F | `Weil1948b` | Companion 1948 Weil monograph developing abelian varieties and algebraic curves, part of the standard primary-source pair behind the function-field RH. Include alongside `Weil1948a` when citing Weil's original framework. |
| F | `Stepanov1969` | Primary source for Stepanov's elementary method for point counts on hyperelliptic curves over finite fields. It is a good historical bridge between Weil's theory and later elementary/expository treatments. |
| F | `Bombieri1974` | Concise Bourbaki exposition of point counting over finite fields after Stepanov, with stable Numdam URL and complete bibliographic data. It is the best short modern-classical source for the discussion section. |
| F | `Lorenzini1996` | Accessible modern arithmetic-geometry text that can support the function-field analogy without relying on the RH companion's already-cited analytic-number-theory sources. Use as a textbook supplement, not as the primary source. |
| G | `Sarnak1990` | Light, standard spectral/modular-forms reference relevant to Ramanujan graphs, trace/spectral methods, and automorphic applications. It is suitable if the DC paper wants a non-Hejhal source for the spectral analogy, while avoiding existing Selberg entries. |
| G | `Venkov1990` | Direct reference for spectral theory of automorphic functions, with explicit chapters on the Selberg trace formula and Selberg zeta function. Use only if Topic G needs a more trace-formula-specific source distinct from the already-shared Hejhal/Selberg references. |
| H | `HillePhillips1957` | Classical functional-analysis source with vector-valued functions and semigroup/integration machinery. It can support the Bochner-style operator-valued integral defining the anti-invariant ledger. |
| H | `DiestelUhl1977` | Standard monograph on vector measures and vector-valued integration. This is the more specialized citation for Pettis/Bochner-style integration issues behind operator-valued ledger integrals. |
| I | `Conway1990` | No new entry is needed beyond Topic A. Conway is the clean textbook citation for operator square roots and polar decomposition, while the already-shared `Douglas1966` remains the canonical range-inclusion/factorization source. |
